## 🚀 Featured projects

### 🐻 [loadbear](https://github.com/weaztoven/loadbear)
A small, friendly load balancer written in Go. Round-robin, weighted, least-connections and IP-hash strategies, active health checks, circuit breaker, rate limiting and Prometheus metrics.

### ⚡ [git-pulse](https://github.com/weaztoven/git-pulse)
Fast, keyboard-driven GitHub TUI tracker in Rust & Ratatui with live in-memory filtering, ETag optimization, and custom hex themes.

Efficient open-source CLI utility built in Rust for fast system cleanup and directory optimization.
